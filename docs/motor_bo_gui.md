# PID 自动整定台：GUI 操作与应用示例

软件通过串口向设备设置 PID、执行有时限的目标试验并接收反馈，负责参数搜索、评分、曲线和 AI 分析；实际控制算法运行在设备端。被控对象可以按项目命名，例如“位置角度”“转速”等；名称和单位用于描述试验，不会自动切换设备控制方式或换算数据。

## 1. 打开界面与保存配置

首次按 [README](../README.md) 安装 Python 和依赖，然后双击 `start_motor_gui.bat`。也可以在项目目录运行：

```powershell
.\venv\Scripts\python.exe motor_bo_gui.py
```

首次启动自动准备本机配置，已有配置不覆盖；启动时不连接串口、不请求 AI。初次生成的模板明确标为速度环示例，使用其他被控对象时需在界面修改；已有用户配置仍按保存值显示，不会为了通用化说明而清空。

| 页面 / 操作 | 填写或查看 | 生效方式 |
|---|---|---|
| 运行配置 → 串口 | 刷新设备列表，选择 COM 口与波特率 | 保存配置；连接时使用 |
| 运行配置 → 实验 | 对象名称、反馈单位、目标列表、时长、轮间等待 | 顶部“保存配置” |
| 运行配置 → 参数区域 | P/PI/PD/PID、基线、搜索范围、固定复测增益 | 顶部“保存配置” |
| 边界与时序 | 设备可接收范围、评分规则、异常判定、超时、随机初始化 | 顶部“保存配置” |
| API | 协议提供方、地址、模型、密钥 | 单独点击“保存API配置” |

保存只更新本机设置，不向设备发送 PID 或启动命令。点击“连接并准备”也会先保存，再执行 PING；收到 OK 后，点击“确认开始”才发送试验命令。出现字段错误时不覆盖原文件；外部修改过配置则需重新加载，避免覆盖。`_注释`及未展示字段会保留。

API 密钥默认遮挡，不写入运行日志；纯贝叶斯与固定复测不使用 API。`MOTOR_BO_*`环境变量仍优先于 API 页保存值。右上角可切换浅色、深色、浅绿主题，主题只影响显示；左侧滚轮与滚动条用于浏览配置，下拉框不会因滚轮误选。

## 2. 选择模式、目标和评分规则

| 选项 | 含义 | 使用条件 |
|---|---|---|
| 贝叶斯调参 / 纯贝叶斯 | 自动提出候选、执行试验、评分 | 不调用 AI |
| 贝叶斯调参 / 贝叶斯＋AI | 在搜索中按间隔分析结果并调整探索倾向，批末可建议下一批范围 | AI 不直接生成 PID，不越过人工硬边界 |
| 固定参数复测 | 同一组增益重复试验，统计评分均值和波动 | 不搜索、不调用 AI、不更新调参历史 |
| P / PI / PD / PID | 分别搜索 P、P/I、P/D、P/I/D | P 固定 I/D 为0；PI 固定 D；PD 固定 I 为0；设备需支持对应参数 |

每轮是一组 PID 依次测试全部目标，不是一个采样点。目标列表支持1～10个不重复数值；例如填写三个目标、搜索20轮，会执行60次目标试验，每次使用配置中的时长并在结束后发送 STOP。目标允许的符号和范围按设备能力配置。

首批随机参数组用于获得不同增益组合的初始样本；随机种子用于复现候选序列，不保证实际测量结果完全重复。“新建历史”建立新系列，“继续同一PID”复用同一对象、同一试验条件的已完成批次；随机初始点只用于新系列首批。对象、目标、单位、时长或评分口径变化后应新建历史。

| 评分设置 | 通用含义 | 举例 |
|---|---|---|
| 设定值跟踪 | 根据目标、起点与反馈评价跟踪误差、超调和稳定时间 | 转速目标变化；其他被控量需按其试验条件设置 |
| 坐标阶跃（如位置角度） | 依据起点到目标的位移尺度评价；默认用首帧估计起点 | 从−60°移动到+60°，阶跃幅度约120° |
| 反馈周期为0 | 误差直接相减 | 绝对位置从−180°到+180°，位移为360° |
| 非零反馈周期 | 按该周期求最短差，仅适用于确实采用循环坐标的对象 | 周期360°的方向角，359°到1°按+2°计算 |
| 容差和归一化下限 | 容差取绝对/相对规则较大值，归一化尺度不小于配置下限 | 角度用度数，温度若以℃收发则这些字段也用℃ |

两种评分类型是评价规则，不是设备控制模式。修改评分选项不会改变设备的误差计算；应让评价坐标与设备实际行为一致。首帧反馈在命令之后产生，只能估计试验起点；目标范围也不等于坐标周期。

分数越低越好，单目标综合跟踪误差、超调和稳定时间；多目标综合分为 `(1-w) × 各目标平均分 + w × 最差目标分`，默认 w=0.3。任何目标无效都会中止剩余试验，不用平均分掩盖失败。比较参数时保持目标顺序、起点规则、运行条件和评分口径一致。

## 3. 查看结果、复测与停止

| 功能 | 操作 | 对数据的影响 |
|---|---|---|
| 曲线与评分 | 表格首列勾选，或点击“全部显示 / 全部隐藏 / 仅显示最优组” | 只改变显示；SVG仍保存全部曲线 |
| 实时日志 / AI中文评价 | 查看逐轮输出与中文建议；“清空日志”只清空日志窗口 | 不删除日志文件、CSV或历史，不停止试验 |
| 最优参数复测 | “所选记录最优 → 复测”或“当前PID历史最优 → 复测” | 填入增益和原试验条件，不自动保存或启动 |
| 查看文件 | “打开记录目录”“打开SVG曲线” | 每目标CSV、逐轮评分、配置、曲线和AI建议由程序保存 |
| 恢复暂停 | 选中AI暂停记录，点击“恢复所选暂停”，握手后确认开始 | 用暂停时配置从下一轮继续，不重跑旧轮 |

多目标曲线按轮次同色，评分表展示各目标独立分数，顶部最佳分为综合分。历史最优导入会核对单位及响应类型，不混用不同被控量的参数；硬边界不会自动扩大。当前 PID 历史最优只读取当前有效系列的已完成批次。

“停止”会通知后台结束采集、发送 STOP 并等待确认，已收到的部分遥测仍保存；STOP 未确认会报告异常。关闭窗口也先请求停止，等待后台退出；AI请求阶段可能要等请求超时。设备本地停止不等于物理过程已完全停止：例如电机会惯性滑行，加热对象会有余热，应按对象配置本地保护与紧急停止措施。

## 4. 应用示例：位置角度

以下只说明绝对位置试验的配置方法，不是所有对象的默认规则。假设设备收发“度”，允许目标为 `[-360,360)`，每次最长5000ms，且使用“目标位置−当前位置”的直接误差：

| 项目 | 示例填写 | 原因 |
|---|---|---|
| 被控对象 / 单位 | 位置角度 / 度 | 名称描述试验，单位与设备数据一致 |
| 目标列表 | `60,-60` | 让两个目标交替形成位移，避免反复保持同一位置 |
| 目标范围 / 时长上限 | 下限−360包含，上限360不包含；5000ms | 这里是假设的设备接受范围，按实际设备修改 |
| 评分 | 坐标阶跃（如位置角度）；首帧反馈估计；反馈周期0 | 与绝对位置直接相减的坐标一致 |
| 负向/近零判定 | 关闭 | 负角度和零角度是合法位置；绝对反馈截止仍保留 |

若开始时已经到达目标，得到的是保持状态响应，不能与完整阶跃等同；低增益未到位时，下一目标也可能从不同起点开始。当前协议没有回零/起点重置命令，需要自行安排一致起点或明确起点规则。用于参数搜索的基线和范围必须根据实际对象确认，不能直接照抄截图增益。

底层兼容接口保留部分历史名称，例如 `motor_bo_gui.py`、`speed_response.svg`和旧配置的 `target_rad_s`；它们不限定被控量。新配置采用 `target_values`、`feedback_unit`等通用字段，旧版缺少单位的记录按原速度记录兼容处理。详见 [串口协议](PROTOCOL.md)。
